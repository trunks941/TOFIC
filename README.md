# TOFIC — programy robota YASKAWA DX200

[Pobierz kompletną paczkę TOFIC_komplet.zip](https://github.com/trunks941/TOFIC/raw/refs/heads/main/TOFIC_komplet.zip), a następnie rozpakuj ją na komputerze.

Paczka zawiera pełny oryginalny zrzut robota, przygotowane programy JBI, raport, porównanie zmian i skrypt weryfikacji offline.

Raport znajduje się w `TOFIC/robot_review/delivery/RAPORT_PL.md`, a zmienione programy w `TOFIC/robot_review/delivery/JBI_REVIEW/`.

Kod jest wersją do weryfikacji na DX200/MotoSim przed użyciem na stanowisku. Nie uruchamiano go na robocie.
